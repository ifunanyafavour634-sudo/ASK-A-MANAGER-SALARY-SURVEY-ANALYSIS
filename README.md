# Ask a Manager Salary Survey 2021 — Salary Analysis

## Project Overview

This project explores salary patterns reported in the 2021 Ask a Manager Salary Survey.

The dataset contains 28,225 survey responses across 18 variables, including annual salary, currency, age, education, gender, professional experience, industry, job title, location, and additional compensation.

The main objective of this analysis is to investigate factors associated with differences in reported salary.

## Key Questions

This analysis will investigate:

* Does professional experience relate to reported salary?
* Does education level relate to salary?
* Which age groups report higher salaries?
* How does reported salary vary by gender?
* Which industries report higher salaries?
* Which job roles report higher salaries?
* Does experience in a respondent's field relate to salary?
* Who receives additional compensation?
* How do salary patterns differ across currencies?

## Dataset

**Source:** Ask a Manager Salary Survey 2021

**Records:** 28,225

**Variables:** 18

Salary is the primary outcome variable in this analysis.

Because respondents reported salaries in different currencies, salary comparisons will account for currency rather than treating all reported amounts as directly comparable.
